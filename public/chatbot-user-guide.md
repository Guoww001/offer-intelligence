## 开始前：认识两种模式

- **Report Mode**：适合输入商家名称、商家 ID、ASIN 或品类，生成一份可查看的分析报告。
- **Chat Mode**：适合基于报告上下文继续追问、澄清和获取分析建议。

## 第 1 步：打开 Chatbot 并在 Report Mode 提问

1. 点击页面上的 Chatbot 助手图标。
2. 确认当前模式为 **Report Mode**。
3. 在输入框中填写商家名称、商家 ID、ASIN 或品类，例如 `Shokz`。
4. 点击“发送”，开始生成报告。

### 示例图

![第 1 步示例图](./user-guide-images/step-01.png)

## 第 2 步：等待 Deep Window 报告

1. 等待 Chatbot 完成分析。
2. 报告完成后，会出现在浮动的 **Deep Window** 中。
3. 如果助手面板挡住了报告，可以先拖动助手面板到合适的位置。
4. 阅读报告中的数据、结论和可用操作。

### 示例图

![第 2 步示例图](./user-guide-images/step-02.png)

## 第 3 步：在报告中点击“加入对话”

1. 在 Deep Window 中确认报告内容已经生成。
2. 点击“加入对话”（英文界面为 **Add to chat**）。
3. 当前报告会被加入 Chatbot 的上下文，供后续对话使用。

### 示例图

![第 3 步示例图](./user-guide-images/step-03.png)

## 第 4 步：确认记忆栏并进入 Chat Mode

1. 点击“加入对话”后，页面会切换到 **Chat Mode**。
2. 在 Chatbot 的记忆栏中确认已经出现当前报告卡片。
3. 如需查看更多输入区域，可以先将 Deep Window 最小化，再查看记忆卡片。
4. 记忆栏中的报告就是后续提问时使用的上下文。

### 示例图

![第 4 步示例图](./user-guide-images/step-04.png)

## 第 5 步：基于报告在 Chat Mode 提问

1. 确认当前模式为 **Chat Mode**，并且记忆栏中保留了报告。
2. 在输入框中提出后续问题，例如“根据刚才的报告，给我分析建议”。
3. 点击“发送”，Chatbot 会结合报告上下文回答。
4. 你可以继续追问，不必重复提交已经加入记忆栏的报告。

### 示例图

![第 5 步示例图](./user-guide-images/step-05.png)

## 完成后的常用操作

- 想生成新的分析报告时，切回 **Report Mode** 后重新提问。
- 想继续讨论当前报告时，保持在 **Chat Mode** 并直接发送问题。
