# Chat Agent 可验证数据来源边界实现计划

**目标：** 对具体数据问题建立“必须有可验证来源”的安全边界，保留方法论、闲聊、已有上下文和用户已提供数据的直接回答能力。

**实现方式：** 在浏览器端规划结果进入直接回答分支前，确定性判断当前问题是否要求具体数据，并检查工具结果、结构化上下文、历史数据回答或用户提供的数值。缺少来源时返回明确的补充信息提示，不把规划模型的无工具文本当作数据结论。
